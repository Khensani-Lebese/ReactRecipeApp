# 🍽️ React Recipe App

## 📌 Overview

The **React Recipe App** is a user-friendly web application that allows users to store, manage, and refer to their favorite dishes. Users can create, update, and delete recipes while categorizing them efficiently.

## 🚀 Features

✅ **User Authentication** – Register and log in securely  
✅ **CRUD Operations** – Create, read, update, and delete recipes  
✅ **Categorization** – Sort recipes into `Breakfast`, `Lunch`, and `Dinner`  
✅ **Styled UI** – A modern and animated interface using `styled-components`  
✅ **Data Persistence** – Uses `json-server` for storing recipe data

## 🛠️ Technologies Used

- **Frontend:** React, React Router, Styled-components, Framer Motion
- **Backend:** JSON Server, Express
- **Other:** Axios for API requests, bcryptjs for password encryption

2️⃣ Install Dependencies:
